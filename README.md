# Service Studio Suite

A production-ready, ultra-modern Single-Page Website Template tailored for Coaches, Consultants, Private Tutors, and Service-Based Entrepreneurs, featuring a Built-in No-Code Admin Panel and Client Booking Flow.

## 🌟 Key Features

### 1. Brand Aesthetic & Public Storefront
- **Design:** Premium, warm-neutral/luxury minimalist aesthetic with smooth scroll, micro-interactions, clean glassmorphism cards, and Lucide React icons. 100% mobile responsive.
- **Sticky Navbar:** Logo/Brand name, navigation links (About, Services, Results, FAQ), and prominent CTA button ("Book Consultation / Free Session").
- **Hero Section:** High-converting headline ("Unlock Your Full Potential with Expert 1-on-1 Guidance"), authority badges ("150+ Clients Coached / 99% Success Rate"), dual CTAs, and a mentor/founder profile card mockup.
- **About & Philosophy:** Split-screen founder story, credentials, core pillars, and quick achievements counter.
- **Services & Pricing Grid:** 3-tier responsive pricing cards (Starter Strategy / Group Class, 1-on-1 Accelerator / Private Tutoring, VIP Intensive) with feature checklists, pricing badges, and "Book Now" buttons.
- **Interactive Consultation & Booking Modal:** Clean popup form triggered by CTAs (Full Name, Email, Phone/WhatsApp, Preferred Service/Class, Date Picker, Message/Goals) with immediate toast confirmation.
- **Results & Testimonials:** Showcase client and student success stories with 5-star ratings and roles.
- **FAQ Accordion:** Accessible questions covering booking, pricing, cancellation, and session formats.
- **Footer:** Newsletter subscription, quick links, contact info, and copyright notice.

### 2. Built-in No-Code Admin Panel (`/admin`)
- **First-Time Admin Setup:** Automatic welcome modal prompting the owner to set their Admin Email and secure Password on the initial visit.
- **Secure Local Authentication:** Credentials and sessions persist reliably in the browser. Includes an option to update email/password inside dashboard settings.
- **Brand & Profile Manager:** Edit Founder Name, Professional Title, Taglines, Bio, Profile Photo URL, and WhatsApp/Social links.
- **Theme & Styling Engine:** 1-Click Preset Color Switcher (Warm Neutral Beige, Modern Emerald Green, Deep Slate Tech, Soft Blush Rose) plus custom Hex color picker to dynamically update CSS accent variables.
- **Services & Packages Manager:** Add, edit, price, and delete custom service tiers.
- **Leads & Bookings Manager:** Real-time table to view, search, export CSV, and mark consultation requests as contacted or completed.

### 3. Whitelabel Architecture & Zero Setup
- **Zero Running Cost:** Pure client-side storage architecture means no mandatory external databases, server bills, or complex API configurations.
- **1-Click Free Hosting:** Deploys out-of-the-box to Vercel, Netlify, or GitHub Pages.
- **Clean Tech Stack:** Vite, React, TypeScript, and Tailwind CSS.

## 🚀 Getting Started

### Local Development

Make sure you have Node.js installed on your machine:

```sh
# Clone the repository
git clone <your-repository-url>

# Navigate into the project folder
cd service-studio-suite

# Install dependencies
npm install

# Start the local development server
npm run dev
